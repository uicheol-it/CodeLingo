# CodeLingo (코드링고) - 모바일 중심 코딩 & 알고리즘 인터랙티브 학습 앱

> **코딩 초보자 및 취업 준비생**을 위한 프로그래밍 문법 및 대표 알고리즘 학습 애플리케이션입니다. 첫 출시 버전은 가장 직관적인 **Python**을 중심으로 완벽하게 제공하며, 점진적으로 추가 언어를 확장할 수 있도록 설계되었습니다.

---

## 💡 주요 특징

1. **초보자 눈높이의 친절한 파이썬 개념 설명**
   - 개발에 필수적인 실제 파이썬 용어(인덱스, 불리언, 함수, 매개변수 등)를 확실히 배우되, *"인덱스(Index)는 데이터가 들어있는 자리 번호(0번부터 시작)"*처럼 직관적인 일상 언어로 풀어서 설명합니다.
   - 6단계 순차 커리큘럼: 변수/자료형 → 연산자/f-string → 조건문(if/else) → 반복문(for/range) → 리스트/인덱스 → 함수(def/return).

2. **모바일 최적화 코드 작성 & 즉시 피드백**
   - 스마트폰 터치 환경에서도 `:`, `()`, `[]`, `""`, `Tab`, `==`, `def`, `print()` 기호를 한 번에 누를 수 있는 모바일 툴바 지원.
   - 브라우저 내장 샌드박스로 파이썬 즉시 실행 및 한국어 에러 가이드.
   - 3단계 점진적 힌트 제공.

3. **6종 대표 알고리즘 인터랙티브 시각화**
   - 수록 알고리즘:
     1. **버블 정렬 (Bubble Sort)** - 인접한 두 수를 비교하여 더 큰 수를 뒤로 맞바꾸는(Swap) 정렬
     2. **선택 정렬 (Selection Sort)** - 최솟값을 찾아 앞자리와 맞바꾸는 정렬
     3. **삽입 정렬 (Insertion Sort)** - 손안의 카드를 정리하듯 알맞은 자리를 찾아 끼워 넣는 정렬
     4. **퀵 정렬 (Quick Sort)** - 기준점(피벗, Pivot)을 중심으로 좌우 분할 정복하는 정렬
     5. **이진 탐색 (Binary Search)** - 정렬된 데이터에서 가운데(Mid)를 확인하고 절반씩 버려가며 찾는 탐색
     6. **하노이의 탑 (Tower of Hanoi)** - 크기 규칙에 맞추어 원판을 옮기는 대표적인 재귀 퍼즐
   - 사전 점검(Pre-test) → 단계별 재생/일시정지/속도조절/파이썬 코드 실시간 동기화 하이라이트 → 사후 검증(Post-test) → 전후 정답 비교.

4. **심화 마스터 가이드 & 12대 핵심 용어사전 (신규 탑재)**
   - **12대 핵심 용어사전**: 반복 가능 객체, 문서화 문자열, 위치 전용 파라미터, 키워드 전용 파라미터, 단락 평가, 시퀀스 언패킹, 네임스페이스, 스코프, 이름 맹글링, 제너레이터, 와일드카드, 데이터클래스 등 실시간 검색 지원.
   - **단답형 평가 퀴즈 10문항**: match 문 vs if, range() 메모리 구조, 루프 else 실행 조건, 가변 기본 인자 누적 원인 등 즉시 채점 및 상세 해설. 틀린 문제는 오답 노트에 자동 누적.
   - **기술면접 심화 서술형 5문항**: 가변 인자 패킹, C3 선형화 MRO 다이아몬드 상속, 어휘 분석 줄 구조, 데코레이터 클로저 아키텍처, 리스트 컴프리헨션 vs 제너레이터 표현식 모범 답안 수록.

5. **100% 클린 스타트 (테스트 데이터 0개)**
   - 신규 사용자가 접속 시 진도 0%, 오답노트 0개, 하드코딩 없는 완전한 초기화 상태로 시작.

5. **단정하고 세련된 미니멀 디자인**
   - 과도한 이모지와 네온 보라색 그라데이션을 걷어내고, 토스/리니어 스타일의 다크·라이트 모드 지원.

## 🏃 실행 방법

### 1. 브라우저에서 바로 열기
파일 탐색기에서 `index.html` 파일을 더블 클릭하여 크롬/엣지에서 즉시 실행할 수 있습니다.

### 2. 스마트폰 및 로컬 서버 실행
```bash
node server.js
```
- PC 접속: `http://localhost:3000`
- 스마트폰 접속 (같은 Wi-Fi): 터미널에 표시되는 IP 주소로 접속
